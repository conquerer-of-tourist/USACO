# Repository guidance

## USACO coaching reviews

When the user requests analysis of Hengsheng's practice history, recent submissions, or progress:

- Follow the review method in `coach-notes/README.md`.
- Write the coach note in English by default, unless the user requests another language.
- Review relevant code and student notes together with available assistance conversations; distinguish independent reasoning from hints, supplied code, and debugging help.
- Tie conclusions to specific evidence, and distinguish local test results, reported AC, verified judge results, and independent mastery.
- Include a concrete follow-up that checks explanation and reconstruction.
- Save the review as `coach-notes/YYYY-MM-DD-coach-note-<topic>.md` and update that folder's index.
- Keep coaching assessments in the separate `coach-notes/` folder.

These instructions concern coaching reviews; they do not require a coach note for routine repository operations or every small code question.
